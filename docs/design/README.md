# Reverb UI デザイン仕様

**ステータス**: Workspace 案を採用  
**対象**: macOS / SwiftUI + AVKit  
**基準仕様**: [`docs/specs/08-playback-ui.md`](../specs/08-playback-ui.md)

## 1. デザイン方針

Reverb の UI は、動画を扱うアプリでありながら、配信サービスではなく「ローカル処理のワークスペース」として設計する。

- 明るい作業面と常設サイドバーを使い、動画・処理状況・設定を同じ場所で扱う。
- 品質優先の処理を隠さず、現在地と完了した工程を静かに伝える。
- 「ローカルのみ」を常時確認できるようにし、プライバシーへの安心感をつくる。
- 画面をカードで埋めず、余白・整列・区切り線を中心に情報を整理する。
- macOS 標準の操作感から外れない。独自の動画編集ソフト風 UI にはしない。

## 4. 変更禁止の確定値

UI 実装でも以下を変更しない。

| 項目 | 値 |
|---|---|
| 日本語音量 | 100% |
| 元音声音量 | 8% |
| STT 既定 | large-v3 full |
| 字幕 | 全角20字前後、最大2行、最低1.5秒 |
| TTS | 単一話者、落ち着いた男性の声 |
| 処理工程 | 音声抽出 → 文字起こし → 翻訳 → 字幕整形 → 音声合成 → ミックス |

## 5. スコープ外

- ファイル書き出し
- 動画ダウンロード
- 字幕・訳文の編集
- 複数話者の割り当て
- リップシンク
- リアルタイム通訳
- クラウド送信やアカウント機能
