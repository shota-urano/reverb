# Reverb デザインシステム

## 1. ウィンドウとレイアウト

- 基準モックサイズ: **1440 × 1024 pt**
- 最小ウィンドウサイズ: **1100 × 760 pt**
- NavigationSplitView を基本とし、サイドバーとコンテンツの2ペインで構成する。
- サイドバー基準幅: **230 pt**、許容範囲 **220〜280 pt**
- コンテンツ外周余白: **32 pt**
- セクション間隔: **28〜32 pt**
- 同一セクション内の要素間隔: **12〜16 pt**
- 行高: 通常 **52 pt**、プロジェクト行 **112〜136 pt**

狭いウィンドウでは、プレーヤーを最優先で縮小し、サイドバーは macOS 標準操作で折りたためるようにする。固定値を維持できない横幅では、音量調整を縦積みに切り替える。

## 2. 色

可能な限り SwiftUI のセマンティックカラーを使う。

| 用途 | 実装方針 |
|---|---|
| メイン背景 | `Color(nsColor: .windowBackgroundColor)` |
| サイドバー | `.sidebar` material または `underPageBackgroundColor` |
| 主テキスト | `.primary` |
| 補助テキスト | `.secondary` |
| 区切り線 | `Color(nsColor: .separatorColor)` |
| 選択背景 | アクセント色 8〜12% |
| アクセント | Indigo 系。基準 `#4F63E9` |
| 成功・接続済み | macOS system green |
| エラー | macOS system red |
| 警告 | macOS system orange |
| 動画面 | 黒〜チャコール |
| 字幕背景 | 黒 68〜76% |

アクセント色は、選択状態・進捗・主要ボタン・スライダーに限定する。広い背景面には使用しない。

## 3. タイポグラフィ

システムフォントを使用し、日本語と英数字でフォントを分けない。

| 用途 | SwiftUI | 目安 |
|---|---|---|
| 画面タイトル | `.largeTitle.weight(.semibold)` | 30〜34 pt |
| プロジェクトタイトル | `.title.weight(.semibold)` | 26〜30 pt |
| セクション見出し | `.title3.weight(.semibold)` | 19〜21 pt |
| 行タイトル | `.body.weight(.medium)` | 15〜16 pt |
| 本文 | `.body` | 14〜16 pt |
| 補足 | `.callout` / `.caption` | 12〜13 pt |
| 字幕 | `.title2.weight(.medium)` | 動画サイズに応じて22〜30 pt |

本文は2行以内を基本とし、技術情報は小さくしすぎず `.secondary` で階層を下げる。

## 4. 形状と境界

- 動画プレーヤー角丸: **12〜14 pt**
- ボタン角丸: **8〜10 pt**
- サムネイル角丸: **8 pt**
- 選択行角丸: **8〜10 pt**
- フォームコントロール高さ: **30〜34 pt**
- 影は動画プレーヤーやポップオーバーなど、面の前後関係が必要な場所だけに使う。
- 通常のリストとフォームは影ではなく区切り線で整理する。

## 5. 共通コンポーネント

### 5.1 AppSidebar

上から次の順で構成する。

1. Reverb ロゴとアプリ名
2. `ライブラリ` / `処理中` / `設定`
3. 区切り線
4. `最近のプロジェクト`
5. 下端の `ローカルのみで動作中`

選択行はアクセントの淡い背景と左端のアクセントバーで示す。最近のプロジェクトはサムネイル、タイトル、日時の3要素に限定する。

### 5.2 LocalOnlyStatus

- 緑の状態点
- 盾または鍵の SF Symbol
- 文言 `ローカルのみで動作中`

常時表示するが、主要操作より強く見せない。依存エンジンに問題がある場合は緑を使わず、クリックで詳細を確認できる状態にする。

### 5.3 ProjectRow

- 16:9 サムネイル
- タイトル
- 任意の短い説明
- 再生時間
- 言語ペア
- 更新日
- 状態
- `…` メニュー

行全体をクリックするとプロジェクトを開く。`…` は補助操作専用とし、行クリックと競合させない。

### 5.4 StageProgress

工程名は API の固定順を日本語表示する。

| API | 表示 |
|---|---|
| `extract` | 音声抽出 |
| `transcribe` | 文字起こし |
| `translate` | 翻訳 |
| `subtitle` | 字幕整形 |
| `tts` | 音声合成 |
| `mix` | ミックス |

状態表現:

- `done`: 青いチェックと `完了`
- `running`: アクセント背景、進捗率、部分進捗バー
- `pending`: グレー、`待機中`
- `failed`: 赤、エラーメッセージへの導線
- `canceled`: グレー、`キャンセル済み`

### 5.5 AudioBalanceControl

- `日本語` と `元音声` を独立したスライダーで表示する。
- 初期値は必ず **100% / 8%**。
- 数値をスライダーの近くへ常時表示する。
- キーボード操作と VoiceOver の調整値読み上げに対応する。

### 5.6 SubtitleOverlay

- 画面下部中央に配置する。
- `subtitles.json` の `lines` をそのまま表示し、UI で再分割しない。
- 最大2行。
- 背景帯は文字幅に合わせ、左右に24〜32 pt、上下に10〜14 ptの余白を取る。
- 動画下端の再生コントロールとは最低20 pt離す。

## 6. アイコン

SF Symbols を使う。独自描画アイコンは追加しない。

| 用途 | 候補 |
|---|---|
| ライブラリ | `folder` |
| 処理中 | `clock.arrow.circlepath` |
| 設定 | `gearshape` |
| ローカル | `lock` / `checkmark.shield` |
| 動画選択 | `folder.badge.plus` |
| 字幕 | `captions.bubble` |
| 音量 | `speaker.wave.2` |
| 完了 | `checkmark.circle.fill` |

## 7. アクセシビリティ

- 通常文字と背景のコントラスト比は 4.5:1 以上。
- 色だけで状態を表さず、アイコンとラベルを併用する。
- クリック対象は最低 28 × 28 pt、主要操作は 32 × 32 pt 以上。
- Dynamic Type 相当の文字拡大で主要情報が欠落しない。
- Reduce Motion 有効時は進捗変化のアニメーションを抑える。
- VoiceOver の読み上げ順は、画面タイトル → 現在状態 → 主要操作 → 詳細情報とする。
