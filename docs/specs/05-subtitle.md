# 05. 字幕整形・字幕表示 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **工程**: ④ 字幕整形 ｜ **担当**: backend（整形）/ frontend（表示）
**ステージ名**: `subtitle`

---

## 1. 目的

翻訳済みセグメントを、読みやすい **字幕キュー（cue）** に整形する。この cue は字幕表示と TTS 生成（[`06`](./06-tts.md)）の共通単位になる。

---

## 2. 入出力

| | 内容 |
|---|---|
| 入力 | `translation.json`（[`04`](./04-translation.md)） |
| 出力 | `subtitles.json`（cue 列。[`09-data-model.md`](./09-data-model.md) §3.4） |

---

## 3. 整形ルール（確定・変更禁止）

要件 v0.6 で確定。実測根拠＋承認なしに変更しない（ルール4）。

| ルール | 値 |
|--------|----|
| 1行の文字数 | 全角 **20字前後** |
| 行数 | 最大 **2行** |
| 最低表示時間 | **1.5秒** 前後 |
| 分割位置 | **意味の切れ目** で分割（文節・句読点・接続詞境界） |

### 3.1 分割・結合の方針

- **長い訳文**（2行×20字に収まらない）→ 意味の切れ目で複数 cue に **分割**。分割時は元セグメントの `start`/`end` を文字量按分等で配分（タイムスタンプ精度向上のため word timestamps を利用可）。
- **短すぎる訳文**（表示が 1.5秒未満になる）→ 隣接 cue と **結合**、または表示時間を最低 1.5秒へ延長（後続 cue と重ならない範囲で）。
- 改行位置は文節境界を優先し、単語・助詞の途中で折り返さない。

### 3.2 タイミング規則

- cue の `start`/`end` は元動画時間軸（[`09`](./09-data-model.md) §2）。
- cue 同士は時間的に重ねない（表示は同時に1 cue）。
- 最低表示 1.5秒を確保するための延長が次 cue と衝突する場合は、間の余白（無音区間）を優先的に使う。

---

## 4. 出力（cue）

`subtitles.json`（[`09`](./09-data-model.md) §3.4）。

- `lines`: 表示行配列（最大2要素）。
- `id`: 0 始まり連番（表示専用）。TTS 音声は translation segment 単位（`tts/seg_%04d.wav`）で合成され、cue とは `segmentIds` 経由で対応する。
- `segmentIds`: 由来翻訳セグメント id（トレーサビリティ）。

---

## 5. 字幕表示（frontend）

- 吹き替え音声と並行して **日本語字幕を常に表示**（[`08-playback-ui.md`](./08-playback-ui.md)）。
- 現在再生時刻に該当する cue の `lines` を表示（最大2行）。
- フォント・サイズ・背景帯等の見栄えは 08 で規定。整形済みテキストをそのまま表示し、UI 側で再折り返し・再分割はしない。

---

## 6. 処理詳細

1. `translation.json` を読み、整形ルールに従い cue 列を生成。
2. 最低表示時間・行数・文字数の制約を満たすよう分割／結合／延長。
3. `subtitles.json` を書き出し、ステージを `done` に。

---

## 7. エラー処理

| 事象 | 対応 |
|------|------|
| 翻訳が空 | 空 cue で `done`（字幕・音声なし） |
| 制約を満たせない極端な入力 | ベストエフォートで整形し継続（ルール超過は許容。黙らず warning をログ） |
