# 08. 再生・プレーヤー UI・設定画面 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **工程**: ⑦ 再生 ｜ **担当**: frontend
**実装**: SwiftUI + AVKit（ネイティブ Mac アプリ）

---

## 1. 目的

処理済みプロジェクトを、**動画 ＋ 日本語字幕 ＋ 日本語吹き替え音声（ボイスオーバー）** で同期再生する。UI 層は処理ロジックを持たず、バックエンド API（[`01-architecture.md`](./01-architecture.md)）の結果を表示・再生する。

---

## 2. 画面構成

| 画面 | 役割 |
|------|------|
| ホーム / 動画選択 | ローカル動画（mp4 主対象）を選択して処理開始 |
| 処理中（進捗） | ステージ別進捗を表示（extract→transcribe→translate→subtitle→tts→mix） |
| プレーヤー | 動画再生＋字幕＋吹き替え、各種コントロール |
| 設定 | 翻訳モデル・TTS 話者・STT モデル等の選択 |
| クレジット / アバウト | VOICEVOX 等のクレジット表記（[`06`](./06-tts.md) §7） |

---

## 3. 動画選択 → 処理開始

1. ファイル選択（mp4 主対象、将来 mov/mkv）。
2. `POST /jobs`（`videoPath` ＋ 任意 `settings`）でジョブ作成。
3. 進捗画面へ遷移。

---

## 4. 処理中（進捗表示）

- `GET /jobs/{id}/events`（SSE）または `GET /jobs/{id}` ポーリングで進捗取得。
- **ステージ別進捗** を表示: `extract / transcribe / translate / subtitle / tts / mix`（固定順・[`01`](./01-architecture.md) §4.2）。
- 全体進捗バー＋現在ステージ名。キャンセルボタン → `POST /jobs/{id}/cancel`。
- 失敗時は `error.message` を表示し、再試行を促す。

---

## 5. プレーヤー（再生）

### 5.1 同期再生

- AVKit で **元動画の映像** を再生。
- **音声**: 日本語吹き替え（[`07-mix-sync.md`](./07-mix-sync.md) の出力）を主音声として同期再生。
- **字幕**: `subtitles.json`（[`05`](./05-subtitle.md)）の cue を現在時刻に同期表示（最大2行）。
- 映像・音声・字幕は同一時間軸（元動画基準）で同期する。

### 5.2 音量バランス（確定初期値）

- **初期値: 日本語 100% / 元音声 8%**（ルール4・[`07`](./07-mix-sync.md) §4）。
- **再生中にスライダーで調整可**: 日本語ゲイン・元音声ゲインを独立または対で制御。
- 実装方式は [`07`](./07-mix-sync.md) §4.1（分離保持 / 合成済み）に従う。UI は方式に応じたゲイン操作を提供。

### 5.3 基本操作

- 再生 / 一時停止、シーク、全体音量。
- シーク時も字幕・吹き替え・元音声が同期して追従。

### 5.4 字幕表示スタイル

- 画面下部中央、最大2行、読みやすい背景帯。
- 整形済みテキスト（[`05`](./05-subtitle.md)）をそのまま表示。UI 側で再折り返し・再分割はしない。
- 表示 ON/OFF トグル（任意）。

## 6. 設定画面

| 設定 | 取得元 | API パラメータ |
|------|--------|----------------|
| 翻訳モデル | `GET /models`（[`04`](./04-translation.md)） | `settings.translate.model` |
| TTS 話者 | `GET /speakers`（[`06`](./06-tts.md)） | `settings.tts.speakerId` / `styleId` |
| STT モデル | 固定肢（large-v3 既定 / turbo）（[`03`](./03-transcription-stt.md)） | `settings.stt.model` |
| 言語 | 自動判定 / 明示指定（[`03`](./03-transcription-stt.md)） | `settings.stt.language` |

- 既定値はバックエンド既定（確定初期値）を初期選択として表示。
- モデル名・話者をハードコードせず、API から動的に一覧取得して提示する（ルール5,6）。
- 設定変更後の再処理は、影響下流ステージのみ再実行（[`09-data-model.md`](./09-data-model.md) §4）。

---

## 7. 制約（UI 層のルール）

- **UI 層に処理ロジックを実装しない**（ルール3）。STT/翻訳/TTS/ミックスはすべてバックエンドへ委譲。
- **連携はローカル HTTP のみ**。別 IPC を勝手に採用しない。
- **確定初期値を勝手に変えない**（音量・字幕表示等）。
- **macOS / Apple Silicon 固定**（ルール10）。

---

## 8. スコープ外

- ファイル書き出し（吹き替え動画の保存）。
- 字幕・訳文の手動編集。
- 複数話者ボイス選択 UI。
（いずれも将来拡張・`docs/requirements.md` §8）
