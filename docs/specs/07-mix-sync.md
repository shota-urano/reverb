# 07. 尺合わせ・音声ミックス（ボイスオーバー生成） 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **工程**: ⑥ 尺合わせ・ミックス ｜ **担当**: backend
**ステージ名**: `mix`

---

## 1. 目的

cue ごとの日本語 TTS 音声を、元動画の発話タイミングに合わせて配置し、元音声を小音量で残した **ボイスオーバー音声** を生成する。

---

## 2. 入出力

| | 内容 |
|---|---|
| 入力 | `tts/cue_%04d.wav`（[`06`](./06-tts.md)）、`subtitles.json` の cue タイミング（[`05`](./05-subtitle.md)）、元音声 |
| 出力 | `voiceover.wav`（全長ミックス。[`09-data-model.md`](./09-data-model.md) §3.6） |
| ツール | **ffmpeg**（サブプロセス）、TTS 再合成（speedScale 適用時） |

---

## 3. 尺合わせ手順（確定・順序厳守）

ルール8。**この順序を崩さない／独自の高度な時間伸縮を入れない**。

```
① speedScale で調整（0.8〜1.3）
       ↓ それでも収まらない分は
② セグメント間の無音区間で吸収
       ↓ なお残る差は
③ 残差は許容（リップシンクは目標にしない）
```

### 3.1 ① speedScale（0.8〜1.3）

- cue の元区間長 `target = end - start` に対し、TTS 音声長を合わせるための話速倍率を算出。
- **範囲は 0.8〜1.3 にクランプ**（範囲外は丸める）。範囲内で収まらない分は ② へ。
- speedScale は TTS 合成パラメータとして適用（[`06`](./06-tts.md) と連携：等速生成→speedScale 指定で再合成、または audio_query に反映）。

### 3.2 ② 無音区間で吸収

- cue 間のギャップ（無音区間）に、はみ出した音声を逃がす／間を詰めることで全体の累積ズレを抑える。
- 元の発話開始タイミングを基準に配置し、後続への押し出しを無音区間で吸収する。

### 3.3 ③ 残差許容

- ②でも吸収しきれないズレは許容する。リップシンクは目標にしない。
- 数値（speedScale 範囲・許容ズレ）はプロトタイプで実測しながら調整余地あり（方針は確定）。

---

## 4. 音量制御（確定・変更禁止）

| 音源 | 初期音量 |
|------|----------|
| 日本語 TTS（主） | **100%** |
| 元音声 | **8%** |

- ルール4：初期値（日本語100% / 元音声8%）を勝手に変えない。
- **再生中にスライダーで調整可**（[`08-playback-ui.md`](./08-playback-ui.md)）。

### 4.1 音量調整の実装方式

再生時に音量バランスを動的変更できるようにするため、次のいずれかを採る（最終判断は実装時）。

- **方式A（推奨・分離保持）**: 日本語ミックス済みトラックと元音声トラックを分離したまま再生層（AVKit）で2系統再生し、UI スライダーで各ゲインを制御。`voiceover.wav` は「日本語のみ全長トラック」とし、元音声は元動画から再生。
- **方式B（合成済み）**: 初期値 100%/8% で合成した `voiceover.wav` を生成。スライダー操作は元動画音声と差し替え可能な範囲で近似。

> どちらでも「初期値 日本語100%/元音声8%」「再生中スライダー調整可」を満たすこと。データモデル上 `voiceover.wav` の定義（[`09`](./09-data-model.md) §3.6）と整合させる。

---

## 5. 処理詳細

1. cue ごとに speedScale を算出（§3.1）。必要なら TTS 再合成を [`06`](./06-tts.md) に要求。
2. 各 cue 音声を `start` 基準で全長タイムライン上に配置（②で微調整）。
3. 元音声とミックス（音量初期値 100%/8%、方式に依存）。
4. `voiceover.wav` を書き出し、ステージ `done`。進捗は cue 配置数で算出。

---

## 6. エラー処理

| 事象 | 対応 |
|------|------|
| 一部 cue 音声欠落 | 当該区間は元音声のみ（無音 TTS）で継続、warning |
| ffmpeg 失敗 | `failed`（code: `MIX_FAILED`、stderr を message に） |

---

## 7. スコープ外

- リップシンク。
- 高度な time-stretch（位相ボコーダ等での自由な伸縮）。speedScale ＋無音吸収のみ。
