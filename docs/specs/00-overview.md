## 1. プロダクト概要

Reverb は、外国語の動画ファイルを **ローカル環境だけ** で「日本語吹き替え音声（ボイスオーバー）＋日本語字幕」付きで視聴できる macOS アプリ。

- **コンセプト**: 元の声が日本語になって返ってくる ＝ Reverb（反響）。
- **方針**: 品質優先（処理が多少遅くても訳・音声の質を取る）。
- **プライバシー / コスト**: クラウド API を使わず、外部送信を一切行わない。利用コストはゼロ。
- **処理方式**: 事前一括処理型（リアルタイム同時通訳ではない）。再生前に全工程を完了させる。
- **対象コンテンツ**: 講義・解説・ドキュメンタリー等、単一話者・ナレーション主体の動画。

## 2. システム全体像

### 2.1 2層サイドカー構成（確定）

```
┌─────────────────────────────────────────────┐
│  UI 層 (SwiftUI + AVKit) ── ネイティブMacアプリ │
│   動画選択 / 再生 / 字幕表示 / 設定 / 進捗表示    │
└───────────────┬─────────────────────────────┘
                │ ローカルHTTP (127.0.0.1, 一時ポート)
┌───────────────┴─────────────────────────────┐
│  処理バックエンド層 (Python サイドカー)          │
│   ジョブ管理 / 処理パイプライン統括 / 進捗通知     │
│                                               │
│   ┌────────┐ ┌─────────┐ ┌────────┐ ┌────────┐ │
│   │ ffmpeg │ │mlx-whis │ │ Ollama │ │VOICEVOX│ │
│   │抽出/Mix │ │ per STT │ │  翻訳   │ │  TTS   │ │
│   └────────┘ └─────────┘ └────────┘ └────────┘ │
└─────────────────────────────────────────────┘
```

- **UI 層**: SwiftUI + AVKit。処理ロジックは持たず、バックエンドの HTTP API を叩いて進捗・結果を取得し、再生・表示・設定のみを担当。
- **処理バックエンド層**: Python 製。Swift が裏でサイドカー起動し、ローカル HTTP で連携。パイプライン全体を統括する。
- **外部エンジン**: ffmpeg（サブプロセス）、mlx-whisper（STT）、Ollama（翻訳 LLM・HTTP）、VOICEVOX（TTS・ローカル HTTP）。

詳細は [`01-architecture.md`](./01-architecture.md) を参照。

### 2.2 処理パイプライン（事前一括処理）

動画選択後、以下を順に一括処理し、中間成果物を保存してからアプリ内で同期再生する。

```
動画(mp4)
  │
  ▼ ① 音声抽出 ........................ 02-audio-extraction.md
audio.wav
  │
  ▼ ② 文字起こし(STT, タイムスタンプ付) ... 03-transcription-stt.md
transcript.json
  │
  ▼ ③ 翻訳(日本語へ / モデル切替) ......... 04-translation.md
translation.json
  │
  ▼ ④ 字幕整形 ........................ 05-subtitle.md
subtitles.json
  │
  ▼ ⑤ 音声合成(TTS) ................... 06-tts.md
tts/seg_*.wav
  │
  ▼ ⑥ 尺合わせ・音声ミックス ............ 07-mix-sync.md
voiceover.wav
  │
  ▼ ⑦ アプリ内 同期再生 ................ 08-playback-ui.md
（動画 + 字幕 + 吹き替え音声）
```

中間成果物のディレクトリ構成・JSON スキーマ・ジョブ管理は [`09-data-model.md`](./09-data-model.md) に集約する。

## 4. 確定済みの初期値（横断・変更禁止）

以下は要件定義 v0.6 で確定済み。**実測根拠＋承認なしに変更しない**（各詳細仕様書でも再掲する）。

| 項目 | 確定値 | 詳細仕様 |
|------|--------|----------|
| 音量バランス初期値 | 日本語 **100%** / 元音声 **8%**（再生中スライダーで調整可） | 07, 08 |
| 尺合わせ | speedScale **0.8〜1.3** → 無音区間で吸収 → 残差許容 | 07 |
| 字幕整形 | 全角 **20字前後** / 最大 **2行** / 最低表示 **1.5秒** / 意味の切れ目で分割 | 05 |
| STT 既定 | mlx-whisper **large-v3 full**（turbo は明示承認で切替） | 03 |
| 元言語 | 英語ベース ＋ Whisper 自動判定で多言語も受ける | 03 |
| 翻訳モデル | 複数モデル切替可（既定候補 Qwen3 30B級）。モデル名は設定値 | 04 |
| TTS 話者 | 落ち着いた男性の声（設定で変更可） | 06 |

## 5. 非機能要件（要約）

| 項目 | 内容 | 状態 |
|------|------|------|
| 動作環境 | macOS / Apple Silicon | 確定 |
| メモリ前提 | 統合メモリ 64GB（Whisper + 翻訳LLM + VOICEVOX 同時常駐可） | 確定 |
| 処理方式 | 事前一括処理 | 確定 |
| 優先度 | 品質優先（遅くても質を取る） | 確定 |
| ローカル完結度 | STT・翻訳・TTS すべてローカル。外部送信なし | 確定 |
| 同期精度 | 尺合わせは行うが残ズレは許容（リップシンク非対応） | 確定 |
| 処理時間目標 | 厳密目標は設けず、実測で許容ラインを把握 | 確定（方針） |
| TTS ライセンス | VOICEVOX 利用規約の確認・順守 | 要確認 |

## 7. 用語

| 用語 | 定義 |
|------|------|
| ボイスオーバー方式 | 日本語 TTS を主、元音声を小音量で残す吹き替え方式 |
| 事前一括処理 | 再生前に全工程を完了させる方式。リアルタイムではない |
| セグメント (segment) | STT/翻訳が扱う、タイムスタンプ付きの発話単位 |
| キュー (cue) | 字幕表示・TTS 生成の単位（整形後。セグメントを分割/結合したもの） |
| speedScale | TTS の話速倍率。尺合わせに使用（0.8〜1.3） |
| サイドカー | Swift が裏で起動する Python バックエンドプロセス |
| プロジェクト | 動画1本分の作業単位。中間成果物一式を保持するディレクトリ |
